KALENSARI STORE - WEBSITE SIAP JALAN

CARA MENJALANKAN:
1. Ekstrak folder/ZIP ini.
2. Buka file index.html di Chrome/Edge.
3. Website langsung bisa digunakan tanpa server.

SEBELUM DIGUNAKAN:
Buka script.js lalu cari:
const WHATSAPP_NUMBER = "6281234567890";
Ganti dengan nomor WhatsApp KALENSARI STORE.
Contoh nomor 081234567890 menjadi 6281234567890.

MENGUBAH PRODUK:
Edit daftar "products" di script.js.
Setiap produk memiliki:
id, name, price, category, emoji, desc.

CATATAN:
- Keranjang tersimpan di browser menggunakan localStorage.
- Checkout dikirim ke WhatsApp.
- Ongkir contoh diatur Rp10.000 melalui SHIPPING_COST.
- Tidak membutuhkan database, hosting, atau server untuk versi dasar.
