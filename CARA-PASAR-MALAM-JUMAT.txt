PASAR MALAM JUM'AT — AKUN KHUSUS PEDAGANG + POP-UP EVENT
========================================================

LANGKAH PASANG
1) Supabase > SQL Editor: jalankan  supabase-pasar-malam.sql  (sekali saja).
   -> akun pedagang Pasar Malam mendapat ID sendiri: PM0001, PM0002, ...
2) Unggah semua file di zip ini ke GitHub (timpa yang lama).
   File lama "pasar-malam.jpg" di folder utama sudah tidak dipakai, boleh dihapus.

AKUN PEDAGANG PASAR MALAM (terpisah dari akun penjual biasa)
- Daftar & masuk:   kalensari.web.id/pedagang-pasar-malam.html
- Aplikasi menu & pesanan:   kalensari.web.id/penjual-app.html?pm=1
  (tampilan malam, judul "Pasar Malam Jum'at", tombol "Daftar lapak")
- ID akun PMxxxx. Bisa masuk pakai nomor WA atau ID PM.
- Akun penjual biasa TIDAK bisa masuk ke aplikasi Pasar Malam, dan sebaliknya
  akun Pasar Malam yang masuk ke Aplikasi Penjual otomatis dipindah ke versi Pasar Malam.
- Satu nomor WA hanya untuk satu akun. Penjual biasa yang ingin ikut Pasar Malam
  daftar lagi dengan nomor WA lain.
- Pedagang mengisi menu, harga, foto, varian — sama seperti toko biasa —
  dan menerima pesanan online: QRIS / COD, diantar kurir, saldo penjualan, pencairan.
- Di halaman akun: tandai BUKA / LIBUR minggu ini, ubah data lapak, ganti PIN, lihat nomor lapak.

JADWAL PESANAN
- Menu Pasar Malam hanya bisa dipesan pada malam acara:
  setiap KAMIS (malam Jum'at) 17.00–22.00 WIB (bisa diubah admin).
- Di luar jam itu warga tetap bisa melihat menu, tombol pesan bertuliskan
  "Buka malam Jum'at 17.00–22.00 WIB". Lapak yang libur: "Lapak libur minggu ini".
- Jadwal ini diatur otomatis; pedagang tidak perlu mengisi jam buka.

DI HALAMAN TOKO
- Pop-up event muncul KAMIS 15.00–21.00 WIB, sekali sehari per HP.
  Tulisan poster: "Setiap Malam Jum'at • Mulai 17.00 WIB".
- Menu Pasar Malam TIDAK tercampur di daftar produk & daftar toko biasa.
  Warga membukanya lewat:
    * tombol "Lihat Denah Event" di pop-up
    * tombol kategori  🌙 Pasar Malam  (di samping 🏪 Toko)
    * menu ☰ → 🌙 Pasar Malam Jum'at
  Lalu ketuk lapak -> menu lapak tampil -> pesan seperti biasa.
- Uji coba pop-up kapan saja:  kalensari.web.id/?pasarmalam=1

ADMIN → Toko & Produk → 🌙 Pasar Malam Jum'at
- Pendaftar baru disetujui di menu Persetujuan (tanda 🌙) -> otomatis masuk daftar.
- Isi NOMOR LAPAK, lihat produk pedagang, keluarkan / masukkan lagi pedagang.
- Atur: hari & jam pop-up, jam acara mulai & selesai (= jam pesanan dibuka/ditutup),
  lokasi, info panitia, gambar DENAH.
- Lapak Pasar Malam tidak muncul di "Daftar Toko" biasa.
