PESANAN PRAORDER • KALENSARI STORE
==================================

CARA PASANG
1) Supabase > SQL Editor > New query > tempel isi  supabase-praorder.sql  > Run.
   Hasil akhirnya harus: kolom_produk = true, kolom_pesanan = true, trigger_praorder = true.
2) Unggah file lain di zip ini ke GitHub (timpa yang lama).
3) Tutup lalu buka lagi aplikasi Mitra Toko, Kurir, dan Kalensari Store supaya versi baru terpakai.

ALUR
- Penjual: Kelola Produk > + Produk / edit > centang "📅 Pesanan praorder" > Simpan.
- Pembeli memesan produk itu -> status MENUNGGU. Toko punya waktu 12 JAM (bukan 15 menit).
  Selama belum diterima, pembeli boleh membatalkan.
- Toko menerima -> status DIPROSES. Pembeli TIDAK bisa membatalkan selama 3 hari.
  Uang ditahan Kalensari Store (masuk saldo toko setelah pesanan selesai, seperti biasa).
  Kurir BELUM dipanggil.
- Toko menekan "📦 Pesanan siap dikirim" -> kurir ditawari, kurir datang ke toko, lalu berjalan seperti biasa sampai selesai.
- Lewat 3 hari dan toko belum menekan "siap dikirim" -> pembeli boleh membatalkan;
  uang kembali sebagai saldo voucher belanja (otomatis, sama seperti pembatalan biasa).

CATATAN
- Satu nota toko berisi produk praorder = seluruh nota itu ikut aturan praorder.
- Praorder harus di-checkout sendiri, tidak bisa digabung dengan toko lain dalam satu checkout.
- QRIS yang belum dibayar tetap batal otomatis 15 menit seperti biasa.
