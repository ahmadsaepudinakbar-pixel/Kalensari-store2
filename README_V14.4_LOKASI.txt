KALENSARI STORE V14.4 - PERBAIKAN IZIN LOKASI

Perbaikan:
- Pemeriksaan HTTPS sebelum meminta lokasi.
- Pemeriksaan status izin lokasi browser.
- Pesan error yang lebih jelas jika izin diblokir.
- Akurasi lokasi tinggi, timeout 15 detik.
- Menyimpan lokasi terakhir ke localStorage.

PENTING:
Website harus dibuka melalui HTTPS, misalnya:
https://kalensari.web.id

Jika izin pernah diblokir:
1. Klik ikon kunci/pengaturan situs di sebelah alamat website.
2. Lokasi -> Izinkan.
3. Muat ulang halaman.
4. Tekan kembali tombol "Gunakan lokasi saya".

Catatan:
Google Maps API Key tidak diperlukan hanya untuk meminta lokasi browser.
