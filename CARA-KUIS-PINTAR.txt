KALENSARI STORE • KUIS PINTAR
=============================

ISI ZIP (hanya file baru / yang berubah)
  BARU   supabase-kuis-pintar.sql   database & fungsi kuis (jalankan di Supabase)
  BARU   kuis.html                  halaman kuis untuk pelajar
  BARU   admin-kuis.html            panel admin: impor Excel, bank soal, pemenang, aturan
  BARU   kuis-pemenang.js           menu "Kuis Pintar" + tombol di toko + popup pemenang
  GANTI  index.html                 tambah 1 baris: <script src="kuis-pemenang.js">
  GANTI  admin.html                 tambah menu "Kuis Pintar" (membuka admin-kuis.html)

LANGKAH PEMASANGAN
1) Supabase > SQL Editor > New query > tempel isi supabase-kuis-pintar.sql > Run.
   Aman diulang. Dipasang di project yang SAMA dengan toko (pakai akun pembeli
   dan saldo voucher yang sudah ada).
2) Unggah 6 file lainnya ke GitHub (satu folder dengan index.html).
3) Buka Admin toko > menu "Kuis Pintar" (atau langsung admin-kuis.html).
   - Tab Aturan: cek poin, hadiah juara 1-3, jumlah & nilai hadiah undian. Simpan.
   - Tab Impor Excel: pilih file soal satu per satu > "Impor".
     File kelas 1-6 SD Anda langsung bisa dipakai (kolom Kelas, Mata Pelajaran,
     Pertanyaan, Pilihan A-D, Kunci Jawaban, Pembahasan Singkat). Sheet gabungan
     dan sheet terpisah berisi soal yang sama: soal kembar otomatis dilewati,
     jadi aman mengimpor ulang. Hasil uji: 8.545 soal unik dari 6 file.
4) Buka kalensari.web.id > menu ☰ > "🎓 Kuis Pintar", masuk dengan akun pembeli, coba main.

ALUR BULANAN ADMIN (awal bulan berikutnya)
  Admin Kuis > Pemenang > pilih bulan lalu:
  1. "Tetapkan juara 1–3"  -> otomatis dari jawaban benar unik terbanyak.
  2. "Undi kupon"          -> acak dari kupon bulan itu (1 orang maks 1 hadiah undian;
                              peluang sebanding jumlah kupon).
  3. Periksa daftar, lalu "Terbitkan + kirim voucher":
     - hadiah langsung masuk SALDO VOUCHER BELANJA akun pemenang
       (tercatat di mutasi voucher, jenis "kuis")
     - popup pemenang muncul di toko (sekali per HP), nama disingkat
       (Asep S.) dan nomor disamarkan (0838****727).
  Selama belum diterbitkan, juara & undian boleh diulang.

ATURAN BAWAAN (bisa diubah di tab Aturan)
  +10 poin per jawaban benar • 100 poin = 1 kupon • maks 100 soal/hari/pelajar
  Juara 1/2/3: Rp50.000 / Rp30.000 / Rp20.000 • 5 pemenang undian x Rp50.000

KEAMANAN
  - Kunci jawaban tidak pernah dikirim ke HP sebelum soal dijawab.
  - Tiap soal hanya bisa dijawab sekali per pelajar (tidak bisa mengulang demi poin).
  - Poin, kupon, dan peringkat dihitung di server, bukan di HP.
  - Tabel kuis tidak bisa dibaca/diubah langsung dari web; hanya lewat fungsi.

KAPASITAS (diuji di PostgreSQL)
  8.550 soal = ±3 MB. 34.000 jawaban = ±5,4 MB (±160 byte/jawaban).
  1 juta jawaban ≈ 160 MB, masih di bawah batas gratis 500 MB.
  Bila suatu saat besar, riwayat jawaban lama (>1 tahun) boleh dihapus;
  poin & kupon yang sudah didapat tidak ikut hilang.

CATATAN PENTING
  Undian berhadiah (walau gratis) umumnya memerlukan izin Kementerian Sosial.
  Mohon dicek sebelum program diumumkan luas.
