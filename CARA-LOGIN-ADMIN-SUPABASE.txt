LOGIN ADMIN KALENSARI STORE - PAKAI SUPABASE (pengganti PIN 1234)
==================================================================

1. Buat akun admin
   Supabase > Authentication > Users > Add user > Create new user
   - Isi email & kata sandi (buat yang kuat, minimal 10 karakter)
   - Centang "Auto Confirm User" > Create user

2. Jalankan SQL
   - Buka file supabase-admin-auth.sql
   - Di baris paling bawah, ganti GANTI_DENGAN_EMAIL_ADMIN@gmail.com
     dengan email admin dari langkah 1
   - Supabase > SQL Editor > New query > tempel semua isi file > Run
   - Hasil terakhir harus menampilkan 1 baris berisi email admin

3. Upload ke GitHub: index.html, script.js, sw.js (+ file SQL & panduan ini)

4. Buka kalensari.web.id > menu ☰ > ⚙️ Admin > masuk dengan email & sandi tadi.
   Kalau masih muncul kolom PIN, tutup & buka lagi aplikasinya (cache lama).

Menambah admin lain : buat user baru (langkah 1), lalu jalankan baris
                      "insert into public.admins ..." dengan email barunya.
Ganti kata sandi    : Supabase > Authentication > Users > (titik tiga) > Reset/ubah password.
Keluar admin        : tombol "🚪 Keluar Admin" di dashboard, atau tutup tab/aplikasi.
