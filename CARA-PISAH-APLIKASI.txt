APLIKASI KURIR & PENJUAL DIPISAH
================================
Sekarang ada 3 aplikasi yang bisa dipasang terpisah di HP (ikon & nama sendiri):
  1) Kalensari Store      -> index.html            (pembeli)
  2) Kalensari Mitra Toko -> penjual-app.html      (penjual + pedagang Pasar Malam)
  3) Kalensari Kurir      -> dashboard-kurir.html  (kurir)
  (+ Admin Notif -> admin-notif.html, sudah terpisah sebelumnya)

LANGKAH PASANG
1) Unggah semua file di zip ini ke GitHub (timpa yang lama), termasuk folder icons/.
2) Di HP: buka kalensari.web.id/penjual-app.html -> menu Chrome -> "Instal aplikasi"
   -> muncul ikon "Mitra Toko". Untuk kurir buka dashboard-kurir.html -> "Kurir KS".
   Kalau dulu sudah memasang ikon Kalensari dari halaman penjual/kurir, hapus dulu lalu pasang lagi.

UNTUK PLAY STORE (nanti)
- PWABuilder: masukkan alamat https://kalensari.web.id/penjual-app.html (Mitra Toko)
  dan https://kalensari.web.id/dashboard-kurir.html (Kurir). Nama paket contoh:
  id.web.kalensari.mitra  dan  id.web.kalensari.kurir
- Setelah dapat SHA-256 masing-masing, tambahkan ke .well-known/assetlinks.json
  (sama seperti id.web.kalensari.twa). Kirim SHA-nya, nanti saya isikan.
