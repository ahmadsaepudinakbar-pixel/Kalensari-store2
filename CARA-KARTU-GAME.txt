KALENSARI GAME • KARTU HERO & SKIN (scan QR)
============================================

ISI ZIP (hanya file baru / yang berubah)
  BARU   supabase-kartu-game.sql   tabel & fungsi kartu (jalankan di Supabase)
  BARU   admin-kartu.html          panel admin kartu: buat kode, unduh stiker/ZIP, daftar klaim
  BARU   qr-mini.js                pembuat QR (tanpa internet/library luar)
  GANTI  game.html                 menu 🃏 Kartu (scan + koleksi), hero terkunci, skin
  GANTI  admin.html                menu baru "Kartu Game" di grup Warga Desa (Pembeli)

LANGKAH PEMASANGAN
1) Supabase > SQL Editor > New query > tempel isi supabase-kartu-game.sql > Run.
   Aman diulang. Tidak mengubah data lain.
2) Unggah file lainnya ke GitHub (satu folder dengan index.html), tunggu Actions ✅.
3) Admin toko > menu "Kartu Game" (atau buka admin-kartu.html).
   Tab "Buat Kartu": pilih hero/skin, kelas, jumlah, nama batch > Buat kode.
   Tab "Ringkasan" > Unduh:
     • Lembar stiker A4  -> Cetak / Simpan PDF, potong, tempel di kartu Anda.
     • ZIP gambar QR + daftar-kode.csv -> untuk percetakan (QR berbeda tiap kartu).
4) Coba: buka game > 🃏 Kartu > Buka Kamera / ketik kode > Klaim.

ATURAN
  • Ocong gratis untuk semua pemain. Hero lain terkunci sampai kartunya diklaim.
  • 1 kode = 1 akun pembeli, selamanya. Kode yang sudah diklaim akun lain ditolak:
    "Kartu sudah dimiliki pemain lain".
  • Kode: KLS-<awalan>-<6 karakter acak>, contoh KLS-KUN-7F3K9Q (tanpa 0 O 1 I L).
  • Salah kode maksimal 10x per jam per akun (mencegah tebak-tebakan).
  • Isi QR = https://kalensari.web.id/game?kartu=KODE
    Discan dengan kamera HP biasa pun langsung membuka game & mengklaim (setelah masuk akun).
  • Admin bisa: menonaktifkan kode (kartu hilang/bermasalah), melepas pemilik
    (klaim keliru), menghapus kode yang belum diklaim.
  • Admin "lihat saja" hanya bisa melihat, tidak bisa membuat/mengubah kode.

SKIN
  Skin saat ini: Kunti Merah (kuntilanak:merah) dan Ocong Emas (pocong:emas).
  Tampilannya sementara memakai pewarnaan dari gambar hero yang ada.
  Pemain memilih skin di menu Karakter (di bawah daftar hero).

MENAMBAH HERO / SKIN BARU NANTI
  1. Hero/skin harus sudah ada di game.html (daftar SKINS / data hero).
  2. Tambahkan juga ke daftar ITEMS di admin-kartu.html (atau pakai "Item lain…").
  id hero: 'kuntilanak', 'pocong', … · id skin: 'hero:nama', mis. 'kuntilanak:merah'
